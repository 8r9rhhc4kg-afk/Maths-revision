# Nat 5 Maths Revision Quiz Show

A self-contained National 5 Mathematics revision website.

## Run it
Open `index.html` in a web browser. No installation or internet connection is needed for the revision content.

## Publish it as a website
To make a public web address, publish the folder using a static website host such as GitHub Pages. The homepage file must be named `index.html`. The public address is created by the hosting service after publishing; this file itself does not create a live URL.

The content is an independent revision aid, not an official Qualifications Scotland resource.
